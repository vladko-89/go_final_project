# Файлы для итогового задания

Структура проекта:

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

Директоория `cmd` содержит основной пакет `main`, что является точкой входа в проект

Директория `internal` содержит пакеты бизнес-логики приложения:
    `date` - обработчик обновления даты
    `static` - обработчик получения статики проекта - файлы из директории `web`
    `tasks` - логика описывающая работу с задачами. В repository.go вынесена логика работы с базой данных. model.go описывает структуру задачи.

Директория `pkg` содержит описание конфигураций, константы и некоторые общие функции используемые в разных местах проекта. 


В приложении есть возможность создать единичную или повторяющуюся задачу с интервалом по количеству дней или интервалом в год. 


Авторизация по паролю, а также поиск задачи остались не реализованными.
